# Bank Management System

## Console-Based Project

### Domain
Banking / Financial Management

### Overview
The Bank Management System is a console-based application developed to manage basic banking operations efficiently. The system allows users to create and manage bank accounts, deposit and withdraw money, transfer funds, check account balances, and view transaction details.

### Main Features
- Create Bank Account
- View Account Details
- Update Account Details
- Deposit Money
- Withdraw Money
- Fund Transfer
- Balance Inquiry
- Transaction History
- Account Management

### Technology Stack
- Programming Language: Python
- Application Type: Console Application
